# Task Behavior Mapping

## Feature Request
- Plan → Implement → Seed test data → Test
- New/revised feature = create or update its seeder (see 03-execution-loop.md SEEDER RULE)

## Bug Fix
- Reproduce → Identify root cause → Fix → Verify
- If the fix changes what a test account should look like, update the affected seeder

## Refactor
- Analyze → Improve structure → Ensure behavior unchanged

## Unknown Task
- Make assumption → proceed → document assumption briefly
