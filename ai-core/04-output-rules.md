# Output Rules

- Be concise
- No unnecessary explanation
- Prefer bullet points or code
- Only include actionable content
- Avoid repetition

## EM DASH RULE (user, 9 Sep 2026)

In any drafted comment, message, or chat prose, do NOT use em dashes as
mid-sentence connectors ("the queue is empty — next session picks up").
Rewrite with a period, comma, colon, or "so"/"and" instead.

The ONLY permitted em dash is the label separator at the start of an item:
"Image 1 — the landing view", "DE-92 — Monthly Repayment box".
